Cross Up | Independent Game Development Studio


My Name is Juno Joseph, I am an independent game developer based in New York City, specializing in mechanics driven gameplay, custom tool implementation, and rapid game loop prototyping. Through my solo studio that I founded (Cross Up), I design and deploy original interactive experiences built on modern game engines.

BACKGROUND

I'm based in NYC and grew up in Harlem. My goal is to one day become a full time Game Developer that creates inspiring and revolutionary games.

Growing up I've always loved playing games with family and friends and enjoyed the fact that it can bring people together. As I developed, I appreciated the impact that some games can have on a person and the message they can have. I also can appreciate how much effort can be poured into every single aspect of a game; from the art, to the mechanics, to even the audio. I've come across many different forms of media which have inspired me to try and do the same for others.

PROJECTS

Feed the Devil

An original system-driven game centered on algorithmic resource management and responsive state changes. Engineered custom asset pipelines, programmatic audio triggers, and dynamic reaction matrices to manage player input dependencies.

Quick Draw

A high-fidelity reaction-based minigame focusing on tight input latency and state verification. Programmed custom responsive animation frames and precise button-press timing validation logic using Unreal's gameplay frameworks.

Knight Platformer

A precision 2D platformer configuration used to master object collision physics and spatial level layout. Hand-calibrated character hitboxes, rigid body interactions, and collision masks to remove tracking bugs and maximize mechanical precision across complex structural hazards.

Mash Runner

A competitive multi-input racer built to test alternate button-mashing mechanics. Implemented anti-simultaneous key verification logic to ensure complex input isolation, player pacing restrictions, and frame-accurate CPU racer AI scaling.
